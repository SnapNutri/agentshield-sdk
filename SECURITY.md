# Security Policy

## Scope

AgentShield is a local Python runtime-protection library. It does not receive
or store project data unless the application supplies an event sink.

## Reporting a Vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Contact
the repository owner through the private security-reporting options available
on GitHub. If private reporting is unavailable, open an issue containing only
non-sensitive details requesting a private contact method.

Do not include credentials, tokens, private data, or exploit payloads in a
public report.

## Support Status

This project does not currently promise a response-time SLA or supported
security-maintenance window.
